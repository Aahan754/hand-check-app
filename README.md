# hand-check-app
Client-side computer vision web app for early Parkinson's screening.
Actual Site: https://handcheck.lovable.app
* **Algorithm Design & Prototyping:** Python (Used for initial signal processing calculations, 4-6 Hz frequency analysis, and spiral geometry validation).
* **Production Web Engine:** JavaScript (ES6+), HTML5, CSS3 (Used for real-time browser rendering, MediaPipe hand tracking, and 100% local client-side execution).
